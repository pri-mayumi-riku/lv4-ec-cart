## 概要
- 架空の小さなお店の商品ページとカートを、1台のブラウザの中で完結させるように作る
- 会員登録、ログイン、決済処理は作らない
- 商品の一覧表示、絞り込み、カート・お気に入り管理機能を組み合わせて実装する
- 商品データは products.json に管理し、JavaScript 側で fetch で取得する
- ページを再読み込みしても、カートとお気に入りに保存された内容がそれぞれ localStorage に残る

## 何のページか
### 音楽ショップのECサイトのカート
- CD・レコード・音楽雑誌を扱う架空の小さなお店のECサイトのカート
- HTML・CSS・JavaScript のみで作成。ライブラリは使わない

## 公開URL
- https://pri-mayumi-riku.github.io/lv4-ec-cart/

## ページの見方
- **タブ** : 「商品一覧」と「お気に入り」タブ。「お気に入り」タブに切り替えると、お気に入りに登録した商品が一覧で表示される。
- **カテゴリボタン** : カテゴリを「すべて」・「CD」・「レコード」・「雑誌」で絞り込む。「すべて」で全商品が表示される。
- **商品カード** : 商品名・カテゴリ・税抜価格・画像（色付きの四角）を表示する。
  - **「カートに入れる」ボタン** : 押すとその商品がカートに入り、ボタンが「カートから外す」に変わる
  - **「カートから外す」ボタン** : 押すとその商品がカートから外れる
  - **お気に入りボタン** : ♡を押すとお気に入りに登録され、❤️に変わる。もう一度押すとお気に入りから解除される
- **カート** : カートに入れた商品が表示される。PCでは画面右側、スマホでは画面下に固定表示される。
  - `-` / `+` ボタンで商品の数量を変える。 `×` ボタンで商品をカートから外す。
  - 一番下にカートに入れた商品の小計（税抜価格の合計）、消費税額（10%）、合計金額（税込価格の合計）を表示する

## 工夫した点
### 画面レイアウト
- **カート・合計金額の固定表示** 
  - カート内の商品や合計金額がすぐに確認できるよう、カート・金額エリアをPCでは画面右側、スマホでは画面下に固定表示
  - カートの商品が増えても合計金額を常に画面下に表示させるため、カートの商品行はスクロールできるようにした
- **画面幅に合わせて商品カードの列表示を変更** 
  - 商品カートのレイアウトが崩れず、かつユーザーに見やすくするため、スマホなど狭い画面幅の場合は商品カードの列数を1~2列、PCの場合は列数を4列で表示するようにした
- **× ボタンの追加**
  - カート内の商品行の `-` / `+` ボタンの隣に `×` ボタンを設置し、押すとカートから外せるようにした
  - （カートから外したいとき、「カートから外す」ボタンを押すため商品一覧から該当商品カードを探す手間を省くため）
 
### エラーハンドリング処理
- **localstorage の読み込み・保存時のエラーハンドリング**
  - 読み込み時にデータがない・壊れている・配列でない場合は空の配列を返すようにして、JavaScript全体が止まらないようにした。
  - 保存時でも `try/catch` で囲み、保存に失敗してもカートやお気に入りの操作を続けられるようにした
- **商品データが読み込めなかった時の処理**
  - `products.json` からの読み込みの成否は `true` / `false` で返し、失敗時は画面に「商品データを読み込めませんでした」と表示するようにした
- **商品データにない商品がカートに残っている場合の処理**
  - ページ読み込み時に、`products.json` にない商品がカートに残っていないか確認し、残っていたら取り除くようにした
  - （もし商品データを変更したり、削除したりしたときに、古い商品データがカートに残っていると、カート操作や価格計算時にエラーになり画面が壊れるため）
